# Простой Word — текстовый редактор для Android

Упрощённый редактор в стиле Microsoft Word (Kotlin, Android 8.0+).

## Возможности
- **Лист A4, который растёт сам**: по мере набора добавляются новые страницы с номерами.
- **Автоувеличение текста при вводе**: пока открыта клавиатура, текст становится крупным,
  а строка с курсором держится в верхней части экрана. Клавиатура скрыта — снова виден лист целиком.
  Масштаб можно менять щипком двумя пальцами (он запоминается). Отключается в меню.
- Полужирный, курсив, подчёркнутый, зачёркнутый; размер шрифта (8–72 pt), цвет текста, выделение цветом.
- Выравнивание по левому краю, по центру, по правому; маркированные списки (Enter продолжает список).
- Отменить / Повторить.
- Открытие и сохранение **.docx** (открывается в Word, Google Docs, LibreOffice) и **.txt**.
- Экспорт в **PDF** и **TXT**.
- **Отправка текста в WhatsApp и Telegram** (выделенный фрагмент или весь документ) и в любое другое приложение.
- Автосохранение: после закрытия приложения документ открывается на том же месте.
- Счётчик слов, знаков и страниц.

## Как получить APK

### Вариант 1 — Android Studio
1. Распакуйте архив, в Android Studio выберите **File → Open** и укажите папку `SimpleWord`.
2. Дождитесь синхронизации Gradle.
3. Подключите телефон (с включённой отладкой по USB) и нажмите **Run ▶**,
   либо **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.

### Вариант 2 — без Android Studio, через GitHub
1. Создайте репозиторий на GitHub и загрузите в него содержимое папки `SimpleWord`.
2. Откройте вкладку **Actions**: сборка «Build APK» запустится сама (≈5 минут).
3. Скачайте архив `SimpleWord-apk` из результатов сборки и установите APK на телефон
   (разрешите установку из неизвестных источников).
